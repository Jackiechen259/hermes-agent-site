Hermes Personal Assistant

A private, single-user automation tool · 个人自用的私人助理

What this is · 这是什么

Hermes is a personal AI assistant running on its owner's own hardware. It is used by exactly one person — its owner — to read and organize their own email, calendar, files and documents. No account other than the owner's can sign in, and no data is collected from anyone else.

Hermes 是运行在本人自有硬件上的个人 AI 助理，仅由账户所有者本人使用，用于整理自己的邮件、日历、 文件与文档。除所有者本人外，没有任何其他账户可以登录，也不收集任何他人的数据。

What it does with Google data · 如何使用 Google 数据

  • Read and search the owner's Gmail messages and labels · 读取与检索本人 Gmail 邮件及标签
  • Read, create and update the owner's Google Calendar events · 读取、创建、修改本人日历事件
  • Read and manage files in the owner's own Google Drive · 读写本人 Google Drive 文件
  • Read and edit the owner's Google Sheets and Docs · 读写本人 Google 表格与文档
  • Read the owner's own Google Contacts (read-only) · 只读本人通讯录

What it never does · 不会做的事

  • Never sells, rents or shares Google user data with third parties · 绝不向第三方出售或共享 Google 用户数据
  • Never uses Google user data for advertising, profiling or training models · 绝不用 Google 用户数据做广告、画像或模型训练
  • Never transfers data to data brokers or information resellers · 绝不向数据中间商转让数据
  • Never allows humans to read the data, except with explicit consent for support, for security purposes, or as required by law · 除经本人明确同意、出于安全目的或法律要求外，不会由人工读取
